## Nedir

Frontend Mentor’un IP Address Tracker görevi için geliştirilmiş bir çözüm. Uygulama açıldığında ziyaretçinin kendi IP konumunu haritada gösterir; ayrıca herhangi bir IP adresi veya alan adı sorgulanabilir. Harita React Leaflet ile çizilir, konum verisi IPify API’sinden alınır.
