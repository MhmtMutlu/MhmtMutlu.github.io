## What it is

sarj.dev is an open-source map application for electric vehicle drivers in Türkiye. It shows charging stations on an interactive map with real-time socket availability and pricing, lets you search, and recommends nearby stations.

## Stack

Built with Next.js and TypeScript. Zustand handles UI state, React Query handles server state and caching, and the map is React-Leaflet. Forms use react-hook-form with Yup, UI pieces come from MUI and notifications from Notistack. Licensed under GPL-3.0.
